What Paste Guard sees
After you click Redact

How it works

1. You copyChecked every half second with macOS's pbpaste.
2. Checks runPatterns, plus official check-digit maths for TFN, ABN, ACN and more.
3. DialogLists what kind of data it found, never the text itself.
4. RedactSwaps each match for a label like [TFN] on your clipboard.

What I cut, and why

The first design had a desktop app, a full PII library and an AI model. The shipped version is one file with no model.

PlannedShippedWhy
Desktop app (Tauri)Terminal scriptmacOS already has a clipboard API and a dialog. No window needed yet.
Microsoft Presidio libraryIts check-digit logic, about 10 linesThe library pulls in hundreds of MB of language tooling. The Australian checks are short maths.
Name-finding modelNothing yetA TFN has a check digit, so a model can't beat maths there. A model only earns its place where patterns can't reach, like names.

What it catches

  • Confirmed by check digit: TFN, ABN, ACN, credit card, IBAN
  • By format: email, Australian phone, Centrelink CRN, street address, state and postcode, IP address, API keys, JWT, private keys
  • By format, after a keyword: BSB, bank account, passport, driver licence, date of birth

What it misses

  • Names. No pattern can tell a name from ordinary words.
  • About 1 in 10 random 9-digit numbers pass the TFN or ACN check, so expect the odd false alarm.
  • It warns when you copy. It can't stop a paste.

Not a security product. A reminder that catches the obvious things, so you can focus on the rest.

Run it

macOS and Python 3.10 or newer. No dependencies.

git clone https://github.com/shrinathprofile/paste-guard cd paste-guard python3 paste_guard.py
